KRISTASIA SCROLLYTELLING PROTOTYPE

Abrir:
1. Descomprime la carpeta.
2. Abre index.html en Chrome/Safari/Edge.
3. Para una prueba más fiel, sirve la carpeta con un servidor local:
   python3 -m http.server 8000
   y visita http://localhost:8000

Incluye:
- index.html
- kristasia-scroll-scrub.mp4
- kristasia-lashes-result-01.mp4
- kristasia-lashes-result-02.mp4
- kristasia-logo.png
- poster.jpg

Notas:
- El video se controla con el scroll.
- La sección de scrollytelling mide 400vh en desktop y 340vh en móvil.
- Este archivo de Gemini sirve para prototipado, pero para producción conviene sustituirlo
  por un master 4K manteniendo el mismo nombre de archivo: kristasia-scroll-scrub.mp4.
